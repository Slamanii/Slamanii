## What I Build

### IDv2 — Cryptographic Voting Protocol
Anonymous voting protocol targeting national elections. Uses HSM integration 
and Pedersen commitments to guarantee voter anonymity, prevent double-casting, 
resist coercion, and aggregate results in real time on Solana. 
Architecture removes the attestor from the trust model entirely — 
no single point of compromise.

`Rust` `Solana` `Pinocchio` `HSM` `PKCS#11` `Pedersen Commitments` `Nullifiers`

[→ View Repository](https://github.com/Slamanii/Idv2)

### ASAP — Distributed Logistics Infrastructure
A distributed API layer unifying pickup and delivery operations across 
a wide network of drivers and customers. Open injection points allow

driver networks into one coherent infrastructure.

`Rust` `Actix-web` `Diesel` `PostgreSQL` `Distributed Systems`

[→ View Repository](https://github.com/Slamanii/Ride-hailing)

### Zazu — Cross-Platform Merchant Assistant
A merchant commerce layer deployed across social platforms at scale. 
Any vendor can program Zazu to serve their customers wherever they 
already are — Telegram, WhatsApp, or any platform with meaningful 
user density. Merchants never have to ask their customers to change behavior.

`TypeScript` `Telegram` `Supabase` `Paystack` `Express`

[→ View Repository](https://github.com/Slamanii/zazu-2.0)

### Circles — Onchain Event Ticketing
Event tickets represented as tradeable tokens on-chain. 
Mint, own, and trade tickets with onchain verifiability — 
eliminates counterfeiting and unlocks secondary market liquidity 
for event organizers and attendees.

`Rust` `Solana` `Tokens` `Onchain`
